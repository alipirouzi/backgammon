## Domain conventions (binding)

**Players.** `Player::White`, `Player::Black`. Absolute point numbering is White's: White moves 24→1 and bears off from points 1–6; Black moves 1→24 and bears off from 19–24. Opening position (White): 2 on 24, 5 on 13, 3 on 8, 5 on 6; Black mirrored: 2 on 1, 5 on 12, 3 on 17, 5 on 19.

**Relative numbering** (engine side): for the player on roll, point `p` (1–24) is *their own* point number: 1 = their ace point, 24 = farthest from home. `25` = bar, `0` = off. The opponent's checkers are expressed on the same axis (opponent's point `q` is my point `25 - q`).

**Dice.** `Dice { hi: u8, lo: u8 }` with `hi >= lo`, both 1–6. 21 distinct rolls; probability 1/36 for doubles, 2/36 otherwise.

**Move / play.** A `Move` is one checker moving one die: `from` (1–24 or 25 = bar), `to` (1–24 or 0 = off), `hit: bool`. A `Play` is 0–4 moves in the order they are made. Two plays are the same play iff they produce the same position; `legal_plays` returns one canonical representative per resulting position (moves sorted by `from` descending, then `to` descending).

**Notation** (relative to the mover, standard): moves separated by single spaces; `from/to`; `bar/` for from 25; `/off` for to 0; `*` after a hitting move; identical consecutive moves collapsed as `13/7(2)`; a hit inside a collapsed group is written `13/7*(2)` only if both hit (otherwise not collapsed). Examples: `24/18 13/10`, `bar/22* 6/2`, `8/4(2) 6/2(2)`, `6/off 5/off`, empty play (no legal move) is the empty string.

**Cubeless equity from probabilities.** `Probs { win, win_g, win_bg, lose_g, lose_bg }` are cumulative from the perspective of the player on roll: `win` = P(win at all), `win_g` = P(win gammon or backgammon), `win_bg` = P(win backgammon), `lose_g`, `lose_bg` likewise for the opponent (P(lose) = 1 − win). Cubeless money equity: `E = 2·win − 1 + win_g + win_bg − lose_g − lose_bg`.

**Match equity.** `met(my_away, their_away) → MWC` from the Kazaross-XG2 pre-Crawford table (25×25, values in [0,1]); `met_post_crawford(trailer_away) → MWC` for the trailer when the leader is 1-away after the Crawford game. Money game (match length 0) uses equity directly.

**Error categories** (equity loss vs best): `Best` (≤ 0.0005), `Fine` (< 0.020), `Error` (0.020 ≤ loss < 0.080), `Blunder` (≥ 0.080). Constants live in `bg_bot::analysis::thresholds` and are asserted by tests; they follow XG's published legend.

**JSON formats.** All cross-binding data is JSON with these shapes (serde, `rename_all = "camelCase"`):


**Produces (exact):**
```rust
pub struct Board { pub white: [u8; 26], pub black: [u8; 26] }            // Serialize/Deserialize per JSON above
impl Board {
  pub fn opening() -> Self;
  pub fn checkers(&self, p: Player) -> &[u8; 26];
  pub fn pip_count(&self, p: Player) -> u32;         // White: sum(n * point); Black: sum(n * (25 - point)); bar counts 25
  pub fn borne_off(&self, p: Player) -> u8;
  pub fn validate(&self) -> Result<(), RulesError>;  // 15 checkers each, no point occupied by both, all counts ≤ 15
}
pub struct Position { pub mine: [u8; 26], pub theirs: [u8; 26] }         // relative; index 0 = off, 1..24 points, 25 = bar
impl Position {
  pub fn from_board(b: &Board, on_roll: Player) -> Self;
  pub fn to_board(&self, on_roll: Player) -> Board;
  pub fn flip(&self) -> Self;                          // swap sides (opponent now on roll)
  pub fn is_race(&self) -> bool;                       // no contact: all my checkers past all theirs
  pub fn all_home(&self) -> bool;                      // mine[7..=25] all zero
  pub fn pips(&self) -> (u32, u32);                    // (mine, theirs)
}
pub struct Dice { pub hi: u8, pub lo: u8 }
impl Dice { pub fn new(a: u8, b: u8) -> Result<Self, RulesError>; pub fn is_double(&self) -> bool; pub fn all() -> [Dice; 21]; pub fn weight(&self) -> u8 /* 1 or 2 */; }
pub struct DiceRng(rand_chacha::ChaCha8Rng);
impl DiceRng { pub fn from_seed(seed: u64) -> Self; pub fn roll(&mut self) -> Dice; pub fn roll_one(&mut self) -> u8; }
pub enum RulesError { InvalidDie(u8), InvalidBoard(&'static str), IllegalPlay(String), WrongPhase(&'static str), NotAllowed(&'static str), Parse(String) }
```
Invariants to test: `from_board` then `to_board` round-trips for both players; `flip().flip() == id`; `Position::from_board(b, White).mine[p] == b.white[p]` and `.theirs[p] == b.black[p]` (same physical point), and `Position::from_board(b, Black).mine[p] == b.black[25 - p]`, `.theirs[p] == b.white[25 - p]`; opening pip count is 167 for both; `Dice::all()` has 21 entries with weights summing to 36; `DiceRng::from_seed(42)` produces the same first 100 rolls as a hard-coded expected list (freeze the list in the test once).

Acceptance: `cd engine && cargo test -p bg-core && cargo clippy -p bg-core --all-targets -- -D warnings && cargo build -p bg-core --target wasm32-unknown-unknown`.

### Task 2: Legal plays and apply

**Files:** `src/moves.rs`, `tests/oracle.rs`.

**Produces:**
```rust
pub struct Move { pub from: u8, pub to: u8, pub hit: bool }
pub struct Play { pub moves: Vec<Move> }                 // ≤ 4
pub fn legal_plays(pos: &Position, dice: Dice) -> Vec<Play>;   // canonical, deduped by resulting position, sorted by canonical move order (from desc, then to desc, move by move — NOT by notation string); returns [Play::empty()] when no move is possible; bindings wrap it unchanged and must not re-sort
```

Rules implemented (cite bkgm.com/rules.html in doc comments): bar first; a point is blocked when `theirs[to] >= 2`; a hit when `theirs[to] == 1` (the hit checker goes to `theirs[25]`, the opponent's bar; the opponent's off is `theirs[0]` — the same index convention as `mine`. Physically their bar checkers enter onto my points 1–6 and they bear off past my 24; `position.rs` module docs are the binding description for Tasks 7–10); bearing off only when `all_home()`, exact die or, when no checker on a higher point, from the highest occupied point; must use both dice if any sequence allows it; if only one die can be used in any order, must use the larger if either order allows the larger; doubles play up to four, as many as possible.

**Oracle (independent):** in `tests/oracle.rs` write a brute-force generator that enumerates die orders `[hi,lo]` and `[lo,hi]` (or four copies for doubles), and at each step tries every `from` 25..=1 with a naive single-checker legality function written from scratch (no imports from `moves.rs` except `Move`/`Play`/`Position` types); collects all maximal-length sequences; then filters to those using the most dice, applies the larger-die rule for one-die plays; dedupes by resulting `Position`. Assert `set(legal_plays) == set(oracle)` on: the opening position for all 21 rolls; 300 proptest-generated random legal positions (generate by playing N random legal plays from the opening with a seeded RNG, plus random bar/off configurations) × random dice.

**Sanity table** (assert exactly): from the opening position, the number of distinct legal plays for each roll — compute with the oracle once, freeze in the test as a 21-entry table with a comment; known anchors: 3-1 → 15? (do not guess: freeze whatever the oracle computes and cross-check two entries by hand in the PR description).

Acceptance: `cargo test -p bg-core --test oracle` runs in < 60 s in debug.

### Task 4: Game and match state, records, replay

**Files:** `src/{game.rs, match_play.rs, record.rs}`, `tests/{rules_golden.rs, game_flow.rs, replay.rs}`.

**Produces:**
```rust
pub struct Cube { pub value: u8, pub owner: Option<Player> }
pub struct Rules { pub jacoby: bool, pub beavers: bool, pub auto_doubles: bool }   // defaults: money game {true,false,false}; match {false,false,false}
pub enum Phase { OpeningRoll, ToRoll, Doubled, ToMove, Finished }
pub enum ResultKind { Single, Gammon, Backgammon }
pub struct GameResult { pub winner: Player, pub kind: ResultKind, pub points: u8 }
pub struct GameState { pub board: Board, pub on_roll: Option<Player>, pub dice: Option<Dice>, pub cube: Cube, pub phase: Phase, pub result: Option<GameResult>, pub rules: Rules, pub cube_dead: bool /* #[serde(skip)]: true during the Crawford game; MatchState restores it on deserialise */ }
impl GameState {
  pub fn new(rules: Rules) -> Self;                                   // Phase::OpeningRoll
  pub fn opening_roll(&mut self, rng: &mut DiceRng) -> Dice;         // each rolls one die, reroll ties; winner is on_roll, dice = (hi, lo), phase ToMove
  pub fn roll(&mut self, rng: &mut DiceRng) -> Result<Dice, RulesError>;   // ToRoll → ToMove
  pub fn legal_plays(&self) -> Vec<Play>;                             // [] when no move; caller then calls play(&Play::empty())
  pub fn play(&mut self, play: &Play) -> Result<(), RulesError>;       // validates via is_legal; detects finish; switches on_roll; phase ToRoll
  pub fn can_double(&self) -> bool;                                   // ToRoll, cube centred or owned by on_roll, cube_dead == false
  pub fn double(&mut self) -> Result<(), RulesError>;                 // → Doubled
  pub fn take(&mut self) -> Result<(), RulesError>;                   // cube.value *= 2, owner = taker, phase ToRoll for doubler
  pub fn drop(&mut self) -> Result<(), RulesError>;                   // finished: doubler wins cube.value points, Single
  pub fn resign(&mut self, kind: ResultKind) -> Result<(), RulesError>;
}
pub struct MatchState { pub length: u8, pub score: [u8; 2], pub crawford: bool, pub post_crawford: bool, pub game: GameState }
impl MatchState {
  pub fn new(length: u8, seed_game_rules: Rules) -> Self;   // length 0 = money/single game
  pub fn away(&self, p: Player) -> u8;
  pub fn cube_allowed(&self) -> bool;                        // false during the Crawford game
  pub fn finish_game(&mut self) -> Option<Player>;           // apply result to score, set crawford/post_crawford, start next game or return match winner
  pub fn is_over(&self) -> bool;
}
pub struct Turn { pub player: Player, pub dice: Option<Dice>, pub action: Action, pub play: Option<String>, pub resign_points: Option<u8> }
pub enum Action { Roll, Move, Double, Take, Drop, Resign }
pub struct Record { pub seed: u64, pub length: u8, pub rules: Rules, pub turns: Vec<Turn> }
pub fn replay(record: &Record) -> Result<MatchState, RulesError>;   // re-derives every roll from the seed; fails if a logged roll/play disagrees
```
Result detection: winner has 15 off; loser 0 off → Gammon; additionally loser has a checker on the bar or in the winner's home board → Backgammon. Points = kind multiplier × cube value, except Jacoby in money games (no double offered this game → single). Crawford: when a player reaches `length − 1` the *next* game is the Crawford game (`crawford = true`, cube not allowed); afterwards `post_crawford = true`. Match to `length` ends when a score ≥ length.

Golden tests (one per cited rule, comments carry the quote and URL from bkgm.com/rules.html and USBGF ruling guide §4.4.8): both-dice obligation; larger-die obligation; bar entry before anything; partial entry forfeits rest; bear-off with higher die; must bear off from highest when no higher; gammon/backgammon scoring; Jacoby; Crawford one game only and cube returns after; beavers off by default (attempt → `NotAllowed`).

Replay test: play 20 seeded random games through `MatchState`/`GameState` logging every `Turn`, then `replay` and assert identical final `MatchState` JSON; mutate one logged play and assert `Err`.

### Task 7: Race evaluation and features

**Files:** `src/race.rs`, `src/features.rs`, `tests/race.rs`.

`pub fn keith_count(pos: &Position) -> (u32, u32)` per Tom Keith (bkgm.com/articles/CubeHandlingInRaces/): pip count + 2 per checker beyond 1 on the ace point + 1 per checker beyond 1 on the 2-point + 1 per checker beyond 3 on the 3-point + 1 per empty point among 4,5,6; the player on roll adds ⌊count/7⌋. `pub fn race_win_probability(pos: &Position) -> f64`: logistic on the adjusted Keith difference calibrated so that Keith's thresholds hold (double when lead ≤ 4 ⇒ ~0.70 win; take when behind by ≤ 2 of doubler's count ⇒ ~0.25 win); gammon probabilities in a race from a simple bear-off heuristic (0 if opponent has borne off ≥ 1 or has all checkers home with ≤ 6 pips deficit; else small). Tests assert monotonicity (more lead → higher win) and the two anchor points within 0.05.

`features.rs`: `pub struct Features { pub pips_mine, pips_theirs, blots_mine, blots_theirs, direct_shots_on_me, indirect_shots_on_me, points_made_mine, points_made_theirs, prime_len_mine, prime_len_theirs, anchors_mine (count of my points in their home board), home_board_points_mine, home_board_points_theirs, checkers_back_mine (in their home board), checkers_back_theirs, bar_mine, bar_theirs, off_mine, off_theirs }` and `pub fn extract(pos: &Position) -> Features`. Shot counting: direct = number of distinct rolls (of 36) that hit a given blot from any opposing checker within 6 pips ignoring blocks, indirect for 7–12 pips; sum over my blots. Tests on hand-built positions (a lone blot 6 away from one checker: 11 direct rolls; 1 away: 11; 2 away: 12; 12 away: 3 indirect).

### Task 8: ClubEvaluator

**Files:** `src/heuristic.rs`, `tests/evaluator.rs`.

`pub struct ClubEvaluator; impl Evaluator for ClubEvaluator`. Classification: `Race` (`pos.is_race()`), `Bearoff` (race and both all home), else `Contact`. Race → Task 7 estimator. Contact → linear score `s = Σ wᵢ·fᵢ` with a documented weight table (one struct literal, weights in doc comments explaining the sign), then `win = σ(s)`, gammon probabilities from checkers back/bar and opponent's off count with caps, all clamped so `win_bg ≤ win_g ≤ win`, `lose_bg ≤ lose_g ≤ 1 − win`. Symmetry invariant: `evaluate(pos).flipped()` ≈ `evaluate(pos.flip())` component-wise within 0.02 for 200 random positions (the evaluator must not favour the side merely for being on roll beyond the on-roll term). Sanity tests: opening position win ∈ [0.48, 0.56]; a position with 5 checkers on the bar against a closed board has win < 0.2; a pure race 40 pips ahead has win > 0.9.

### Task 9: Search, levels, rollouts

**Files:** `src/search.rs`, `src/rollout.rs`, `tests/search.rs`, `tests/rollout.rs`.

```rust

pub struct SearchParams { pub keep_top: usize /* 5 */, pub two_ply: bool, pub noise_sigma: f64, pub rollouts: u32 /* 0 = none */, pub rollout_depth: u32 /* plies, default 8 */ }
impl Level { pub fn params(self) -> SearchParams; }   // Beginner {5,false,0.05,0,_}, Intermediate {5,false,0,0,_}, Club {5,true,0,100,8}
pub struct Candidate { pub play: Play, pub equity: f64, pub probs: Probs, pub rollout: Option<RolloutStats> }
pub struct RolloutStats { pub trials: u32, pub equity: f64, pub std_err: f64, pub probs: Probs }
pub fn rank_plays(ev: &dyn Evaluator, ctx: &MatchContext, pos: &Position, dice: Dice, params: &SearchParams, seed: u64) -> Vec<Candidate>;  // sorted by equity desc; equity is match-normalised via equity_for
```
1-ply: for each legal play apply → evaluate the flipped position → negate/flip probs. 2-ply refinement for the top `keep_top`: expected value over the 21 opponent rolls (weights 1/36, 2/36) of the opponent's best 1-ply reply. Noise: add `N(0, σ)` from the seeded RNG to each 1-ply equity before ranking (Beginner). Rollouts: for the top `keep_top` after 2-ply, `trials` truncated rollouts: both sides play 1-ply best plays for `rollout_depth` plies from a seeded `DiceRng` derived from `seed + candidate_index`, then the static evaluator scores the terminal position (or the actual result if the game ended); `equity` = mean, `std_err` = sd/√n; candidates re-sorted by rollout equity when present. Determinism test: same inputs and seed → identical output JSON; different seed → same set of plays. No `std::time`, no threads.

### Task 10: Cube decisions and analysis

**Files:** `src/cube.rs`, `src/analysis.rs`, `src/bot.rs`, `tests/analysis.rs`.

Dead-cube MET model (documented as such; Janowski x = 0): with `p = ev.evaluate(pos)` for the player considering a double, compute MWC for `no double` (game played at current cube), `double/take` (cube doubled, then game played cubeless), `double/drop` (I win current cube value). Money game uses equities: ND = E, DT = 2E (capped in [−2, 2]... use `2·E` then compare with DP = +1). Action rules: double if `DT > ND` and `DT ≤ DP`... precisely: if `DT > ND`: recommend double; opponent takes if `DT < DP` (from opponent's view: take point where taking is better than dropping), else drop (`doubleDrop`); if `DT ≥ DP` and win probability is so high that not doubling is better (gammon chances): `tooGood`. Redouble variants when the cube is owned by me. `takePoint` = the win probability at which take equals drop under this model. Crawford / dead cube → `noDouble` always with `can_double = false`.
